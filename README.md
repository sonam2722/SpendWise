# SpendWise – Student Expense Tracker

SpendWise is a responsive web application designed to help students track, manage, and understand their daily expenses.

## Features

- Add, edit and delete expenses
- Search and filter expenses
- Date-range filtering
- Monthly expense tracking
- Finance and budget management
- Daily, monthly, category and yearly spending charts
- Smart spending analytics
- Automatic spending insights
- CSV export
- PDF expense reports
- Expense reminders
- LocalStorage data persistence
- Dark mode
- Responsive mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- jsPDF
- Browser LocalStorage
- Responsive Web Design

## How It Works

Users can add their expenses with a title, amount and category. SpendWise stores the data locally in the browser and generates charts and analytics to help users understand their spending patterns.

The application also allows users to export their financial information as CSV or PDF reports.
